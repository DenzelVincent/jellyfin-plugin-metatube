MetaTube

MetaTube Plugin for Jellyfin/Emby. Learn more.

General

Full url of the MetaTube Server, HTTPS protocol is recommended.
Access token for the MetaTube Server, or blank if no token is set by the backend.
Automatically create collections by series.
Create one collection per actor from MetaTube metadata. Maintained by the "同步演员合集" scheduled task (Jellyfin only).
No selection means all libraries. Only movies from selected libraries are added to actor collections; MetaTube movies outside the selection are removed from existing actor collections and the no-actor collection. (Jellyfin only)
Gates creation only: an actor needs at least this many movies to get a new collection, existing collections keep syncing even below the threshold. Set 1 to create one for every actor. Blank falls back to 3. (default: 3)
Writes each collection's live movie count into its own community rating, so the library page's Ratings sort orders collections by count. The stars show the count, not a rating. Collections this plugin never touched keep no value. (default: off)
Add directors to corresponding video metadata.
Display community ratings from the original website.
Generate online video trailers in strm format.
Search and replace with real actor names from AVBASE.

Badge

Add Chinese subtitle badges to primary images.
Custom badge url, PNG format is recommended. (default: zimu.png)
Files ending with these keywords are treated as having Chinese subtitles, comma separated. (default: C,UC,ch,中文字幕)
Language codes of sidecar subtitle files, comma separated. (default: chs,cht,chi,zh,zh-cn,zh-tw,zho)
Add an uncensored badge to the top right corner of primary images, requires uncensored.png on the backend.
Files containing these keywords are treated as uncensored / AI-restored, comma separated. (default: U,UC,AI,uncensored,无码,破解,LTX,wm,restored,jasna)
Uncensored badge image name, served by the backend. (default: uncensored.png)

Image

Aspect ratio for primary images, set a negative value to use the default.
Rewrite pics.dmm.co.jp cover URLs to the 2184×1468 version on awsimgsrc.dmm.co.jp. Applies to DMM-based sources (JavBus, JAV321, FANZA); covers without a cid stay unchanged. Off by default.
Default compression quality for JPEG images, set between 0 and 100. (default: 90)

Provider

Filter and reorder search results from movie providers.
Provider names are case-insensitive, with decreasing precedence from left to right, separated by commas. Available: JavBus, FANZA, JAV321, AVE, MGS, AVBASE, GFriends, 10musume, 1Pondo, AiRav, AV-LEAGUE, AVSOX, C0930, Caribbeancom, CaribbeancomPR, DAHLIA, DUGA, FALENO, FC2, fc2hub, FC2PPVDB, FREEJAVBT, Gcolle, Getchu, H0930, H4610, HEYZO, HeyDouga, IQQTV, JAVFREE, JavDB, KIN8, MadouQu, MINNANO, MURAMURA, MYWIFE, OFFICIAL, PACOPACOMAMA, Pcolle, SOD, ThePornDBMovie, ThePornDBScene, TOKYO-HOT, Wikipedia. (default: JavBus,FANZA,JAV321,AVE,MGS,AVBASE,GFriends)
Merge fields across providers: title, plot and cover can each come from a different source.
Per-field provider order, e.g. "Title:JavBus,FANZA;Summary:FANZA,JavBus". Fields: Title, Summary, CoverURL, Director, Actors, Genres, Series, Maker, Label, Score, Runtime, ReleaseDate, PreviewImages.
JavDB anti-bot cookie, copy from your browser after logging into javdb.com. Leave blank to disable.
